Loading Screen

A modern, visually stunning loading overlay component for web applications. Features smooth animations, multiple progress indicators, and easy customization.

// Show loading screen LoadingScreen.show('Signing you in...'); // Hide after task completes LoadingScreen.hide(() => { console.log('Loading complete!'); }); // Change theme LoadingScreen.setTheme('light'); // Custom options LoadingScreen.show('Loading...', { theme: 'dark', progressType: 'bar', backdropBlur: true });
